# deck-rules.md - durable preferences for this user's decks

Read this FIRST on every deck. Obey it as defaults. After every review, append what the user corrected (one dated line each: complaint -> measured fix -> rule).
Keep it next to the deck (default `./deck-rules.md` in the deck folder).

## Standing rules (seeded from observed feedback, 2026-11)

- Language: Vietnamese with full diacritics; academic register; canonical course terminology.
- Type: body 34-38 px, support 30-34, titles 52-60 on 1920x1080; never below 32 px for anything to be read. ("font bự hơn" is the recurring complaint: obey from the first draft.)
- Consistency: one font system, one accent, same title position, same left margin on every slide; sibling cards/rows have identical line counts.
- Visuals: real diagrams (spiral, cycle, chain) over decorative art; many worked examples (3-4) from different domains; no stock imagery, no 3D, no gradients.
- Use the user's own art (engraving band) on cover and closing; never invent art when the image-credit quota is exhausted.
- "Làm lại slide này" = build a NEW design; keep the original untouched; share the new link.
- Notes and Q&A live in a sidecar file (Canva cannot write presenter notes through this MCP).
